# Maze of Screams - Horror Maze Escape Game

迷い込んだ廃病院から脱出せよ！途中で幽霊に捕まるな！

ブラウザで遊べます👇

➡ [https://tak-raiden.github.io/maze_of_screams/]
## 操作方法
- タイトル画面：Enterキーでゲームスタート。
- カーソルの上下左右またはWASDで移動。
- SHIFT+移動：ダッシュ
- 幽霊に捕まらないようにゴールを目指せ。
- Mボタンを押すと5秒間だけマップが使える。その後は10秒間のインターバルでまたマップが5秒間使えるようになる。
- マップ上、ピンクの四角が「自分」、赤の四角が「幽霊」、青の四角がその階の「スタート地点」、黄色の四角がその階の「ゴール地点」。
- ゲームオーバー時にスペースを押すと4Fから再開、Qでタイトル画面に戻る。
